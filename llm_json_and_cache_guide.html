② 🍎 사과 ➔ 🍇 포도 ➔ 🍌 바나나: 중복 전송과 Cache Hit 시뮬레이터

            
턴을 하나씩 진행해 보세요. 매번 이전 대화를 중복해서 다 보내지만, 서버가 어떻게 Cache Hit(90% 할인)로 처리하는지 볼 수 있습니다.

          

          

            
            
            
          

        


        

          
        


        

          
📌 프롬프트 캐시(Prefix Cache)의 절대 조건: "맨 앞부터 토씨 하나 안 틀리고 똑같아야 한다!"

          

            LLM 서버는 JSON의 맨 앞(Prefix)부터 순서대로 이전 요청과 글자가 일치하는 구간까지만 캐시(KV Cache)를 적용해 줍니다. 만약 중간에 있는 '사과' 내용을 한 글자라도 고치면 그 뒤에 있는 '포도', '바나나' 캐시는 도미노처럼 전부 깨집니다(Cache Miss).
          

        

      

    


    
    

      
      

        

          
① 왜 `/compact`를 자주 누르면 오히려 요금(Limit) 폭탄을 맞을까?

          

            현재 대화가 50,000 토큰(옛날 대화 30,000 + 최근 보존 대화 20,000) 쌓여 있을 때, 아래 3가지 행동 중 무엇을 선택하느냐에 따라 실제 차감되는 토큰 비용이 최대 7배~10배 차이 납니다!
          

        


        
        

          

          

          
        


        
        

          
        

      


      
      

        

          

            
② 🎁 보너스: 직접 만드신 Usage 익스텐션에 '5분 캐시 수명 타이머' 추가하기

            

              서버 GPU VRAM의 캐시는 보통 마지막 응답 후 5분(300초) 동안 아무 대화가 없으면 자동 삭제됩니다. 상태바에 카운트다운을 띄워두면 언제 생토큰이 나가는지 한눈에 알 수 있습니다!
            

          

        


        
// .pi/extensions/cache-ttl-timer.ts
// 마지막 턴 종료 후 5분(300초) 카운트다운을 상태바에 실시간으로 표시하는 익스텐션
export default function (pi) {
  let lastTurnEndTime = null;
  let timer = null;
  const CACHE_TTL_SECONDS = 300; // 기본 5분 (Anthropic / OpenAI 기준)

  pi.on("agent_end", (_event, ctx) => {
    lastTurnEndTime = Date.now();
    if (timer) clearInterval(timer);

    timer = setInterval(() => {
      const elapsed = Math.floor((Date.now() - lastTurnEndTime) / 1000);
      const remaining = CACHE_TTL_SECONDS - elapsed;

      if (remaining > 60) {
        const min = Math.floor(remaining / 60);
        const sec = String(remaining % 60).padStart(2, "0");
        ctx.ui.setStatus("cache-ttl", `🟢 Cache HOT (${min}:${sec})`);
      } else if (remaining > 0) {
        ctx.ui.setStatus("cache-ttl", `🟡 Cache Dying (${remaining}s!)`);
      } else {
        ctx.ui.setStatus("cache-ttl", `🔴 Cache COLD (만료됨 - /compact 또는 /new 권장)`);
        clearInterval(timer);
      }
    }, 1000);
  });
}
